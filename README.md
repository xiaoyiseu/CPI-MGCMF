## Usage
### Requirements
we use a single NVIDIA A6000 GPU for training and evaluation.  

```
python 3.8.19
torch 2.3.0+cu121
torchvision 0.18.0
numpy 1.22.1
pandas 2.0.3
pillow 10.3.0
Pkuseg 0.0.25
BERT ‘bert-base-chinese’ (HuggingFace)
```

python train.py
